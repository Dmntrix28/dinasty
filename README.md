# dinasty

Landing visual estilo **GTA Dynasty** enfocada en **La Paz, Bolivia**, publicada para GitHub Pages.

## Página pública
- URL esperada: `https://dmntrix28.github.io/dinasty/`

## Qué contiene
- `index.html`: interfaz principal visible en GitHub Pages.
- `styles.css`: tema neón/HUD tipo GTA.
- `app.js`: listado mock de inmuebles + filtros + mapa Leaflet en La Paz.
- `gta-dynasty-bolivia/`: monorepo full-stack (frontend React + backend Spring Boot).

## Importante
GitHub Pages solo publica archivos estáticos. Por eso la vista principal para tu enlace está en la raíz del repo (`index.html`).

## Si no ves cambios
1. Ve a **Settings → Pages**.
2. En **Build and deployment**, selecciona:
   - **Source:** Deploy from a branch
   - **Branch:** `main`
   - **Folder:** `/ (root)`
3. Guarda y espera 1-3 minutos.
4. Haz hard refresh (Ctrl+F5) en tu URL.
